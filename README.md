# 📊 Data Analysis on BIST100 – A 2022 Market Insight with Python

This project is a comprehensive data analysis of the BIST100 (Borsa Istanbul 100) index for the year 2022, developed as part of my summer internship in 2023. It combines real-world financial data with powerful Python tools to uncover meaningful patterns and visual insights from the Turkish stock market.

> If you're passionate about **data science**, **finance**, or **Python analytics**, this project demonstrates how raw market data can be transformed into actionable insights.

---

## 🚀 Overview

- Analyzes daily stock prices and trading volumes for BIST100 companies throughout 2022.
- Extracts trends, compares distributions, and visualizes monthly market behavior.
- Uses Python libraries like **Pandas**, **Seaborn**, and **Matplotlib** to turn financial data into clear, readable graphics.

---

## 📁 Files Included

| File | Description |
|------|-------------|
| `DersNotları.ipynb` | Contains data loading, cleaning, preprocessing, and basic exploratory analysis. Lays the groundwork for deeper visual insights. |
| `DersNotları2.ipynb` | Includes advanced visualizations (line plots, boxplots, bar charts, histograms) to compare stock performance across months and sectors. |
